a. GenBank File Format and SeqRecord Object

GenBank is a standard biological file format developed by the National Center for Biotechnology Information for storing nucleotide and protein sequence information along with detailed annotations. It is widely used in bioinformatics to exchange and manage biological sequence data.

A GenBank file contains:

Sequence identification information
DNA or RNA sequence data
Gene annotations
Protein information
Organism details
References and biological features

In Biopython, the SeqRecord object is used to represent a biological sequence together with its associated metadata and annotations. It stores information such as:

Sequence ID
Sequence name
Description
Features and annotations
DNA, RNA, or protein sequence

The SeqRecord object helps researchers organize sequence data efficiently and export it into different biological file formats such as GenBank, FASTA, and EMBL.

Annotations like gene name, molecule type, and protein function can be stored using the annotations dictionary inside the SeqRecord object. These annotations are included automatically when the sequence is written to a GenBank file.

Thus, the SeqRecord object provides a convenient and structured way to store, manage, and export biological sequence data along with its related information in bioinformatics applications.


b. Python Program to Write DNA Sequence and Annotations to a GenBank File

from Bio.Seq import Seq
from Bio.SeqRecord import SeqRecord
from Bio import SeqIO

def write_genbank():
    dna_sequence = Seq("ATGCGTACGTAGCTAGCTAG")

    record = SeqRecord(
        dna_sequence,
        id="seq1",
        name="Example_Gene",
        description="Example gene sequence",
        annotations={
            "molecule_type": "DNA",
            "gene": "ExampleGene",
            "function": "Hypothetical protein"
        }
    )

    output_file_path = "q4_genbank.gb"

    with open(output_file_path, "w") as output_file:
        SeqIO.write(record, output_file, "genbank")

    print("GenBank file written successfully.")

    with open(output_file_path, "r") as input_file:
        record_read = SeqIO.read(input_file, "genbank")

    print("\nContents of the GenBank file:")
    print(record_read)

write_genbank()
